Comment lire la heatmap

Correlation de Pearson

Ce que mesure la heatmap

Chaque case compare deux variables (ex: PM2.5 et densite). Le chiffre affiche leur lien statistique, note r. Plus r est proche de +1, plus elles montent ensemble. Plus r est proche de -1, plus l'une monte quand l'autre baisse. Autour de 0, il n'y a pas de lien clair.

r = cov(X, Y) / (sigmaX * sigmaY)

cov = covariance, sigma = écart-type. Calcul fait uniquement sur les villes qui ont les deux valeurs.

Exemple simple

Si r = 0.70 entre "Electricite charbon" et "PM2.5", cela signifie que les villes avec plus de charbon ont tendance a être plus polluees.

Cliquez sur une case pour voir le nuage de points correspondant.
