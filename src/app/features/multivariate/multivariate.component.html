Comprendre l'ACP

Analyse en composantes principales

Pourquoi l'ACP ?

L'ACP (Analyse en Composantes Principales) sert a reduire la dimension. On remplace p variables par de nouvelles variables C1, C2, ... qui résument au mieux la variabilit? des données.

Z = (X - moyenne) / écart-type

On centre et reduit les variables pour les mettre sur la meme echelle.

Vx = (1/n) * Z^T * Z

Vx est la matrice de variance-covariance (symétrique, définie positive).

Vx = P D P^T

P contient les vecteurs propres orthonormes, D les valeurs propres (lambda).

C = Z * P

P contient les vecteurs propres u1, u2, ... de Vx. Les composantes sont Cj = Z * uj.

Ce que disent les valeurs propres

Vx = P D P^T, avec D = diag(lambda1, lambda2, ...). La variance de Cj vaut lambda_j et les composantes sont non correlees (Cov(Ci, Cj) = 0).

L'inertie globale est Ig = somme(lambda). La part expliquee par l'axe j est lambda_j / Ig. On garde les axes qui expliquent la majorite de l'inertie.

Gestion des données manquantes

Les valeurs manquantes sont remplacees par la moyenne de la variable (imputation) afin de conserver un maximum de villes.

Les variables trop manquantes ou sans variance sont retirees automatiquement. Un avertissement apparait si l'ACP ne peut pas être calculee correctement.

Le panneau "Filtrés ACP" affiche le nombre de variables actives prises en compte.

Que signifie PC1, PC2, PC3 ?

Chaque PC est une combinaison lineaire des variables. Les "loadings" (coefficients) indiquent quelles variables poussent l'axe. Un coefficient positif signifie que l'axe augmente quand la variable augmente; un coefficient negatif signifie l'inverse.
